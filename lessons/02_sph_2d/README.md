# 阶段 02 前置样本：Poly6 密度估计可视化

> 这是正式开始阶段 02 之前的热身样本——只做密度估计这一步，不含压力、不含真实流体。
> 对应 [docs/LEARNING_PLAN.md](../../docs/LEARNING_PLAN.md) 阶段 02 的第一、二条任务。

## 运行

打开 `lessons/02_sph_2d/DensitySample.tscn`，F6 运行。**按住鼠标左键**推开粒子。

## 你会看到什么

- 256 个粒子排成网格，**颜色 = 密度**：蓝 ≈ 静止密度 ρ0，越红越密，越稀越偏紫/蓝
- 鼠标推开的区域粒子变稀（蓝色/深色），被挤到的边缘变红——这就是"密度是被数出来的"的直观形态
- 白色圆圈：跟随鼠标最近粒子的**核半径 h**，圈内粒子才给圆心贡献密度
- 左上角实时显示平均密度 ρ_avg（静止时应接近 ρ0 = 1）和最大密度

## 核心代码只有两个函数

- `ComputeDensities()` —— 密度公式 ρᵢ = Σⱼ mⱼ·W(rᵢⱼ, h) 的直译，注意：
  - 求和**包含 j = i 自己**（自己给自己的贡献最大）
  - O(n²) 暴力双循环，256 粒子 × 256 = 6.5 万次每步，毫无压力；3000 粒子就不行了 → 空间哈希是正式阶段的第一课
- `Poly6(r2)` —— Poly6 核，只依赖 r²，参数直接收 r² 避免开方

质量取 `m = spacing²`（ρ0 = 1 时 2D 的正确取法），所以静止网格的 ρ_avg 会自动落在 1 附近——这就是"核函数归一化"的意义，试着把 `Mass` 改成 `Spacing * Spacing * 2` 看 ρ_avg 变成 2。

## 动手实验（每个实验对应一个理解点）

1. **改 H（核半径）**：40 → 80。白圈变大，单个粒子的邻居变多，ρ_avg 怎么变？为什么（提示：归一化常数里有 h⁸）？
2. **改 Mass**：×2 后静止时 ρ_avg 还是 1 吗？想要 ρ_avg = 1 该怎么补偿？
3. **去掉自身贡献**：把邻居循环里 `j == i` 跳过，ρ_avg 掉多少？自身贡献占比能说明什么（提示：Spacing 相对 H 很小时自身贡献很大）
4. **把 Spacing 改成 30**：粒子更稀，ρ_avg 如何变化？这解释了 SPH 里"密度不足 → 粒子互相吸引"（压力为负）的现象来源
5. **用力按住鼠标**：被挤区域 ρ_max 冲到多少？真实流体里这种挤压会由压力项顶回去——我们下一节就写压力
